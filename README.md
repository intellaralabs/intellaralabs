## 🎛️ Open source: Thock UI

**Tactile React components you can almost feel.** Raised keys, recessed wells, LEDs, knobs and faders, built on
React 19, Tailwind CSS v4 and Radix UI. Install any component with the shadcn CLI. Free and MIT-licensed.

```bash
npx shadcn@latest add https://thock-ui.vercel.app/r/button.json
```

| Repository | What it is |
| --- | --- |
| [**thock-ui**](https://github.com/intellaralabs/thock-ui) | The component library and docs site: 30 components and 2 blocks |
| [**thock-finance-lite**](https://github.com/intellaralabs/thock-finance-lite) | Harbor Lite: a free personal finance dashboard |
| [**thock-smart-home-lite**](https://github.com/intellaralabs/thock-smart-home-lite) | Maple House Lite: a free smart home dashboard |
| [**thock-studio-lite**](https://github.com/intellaralabs/thock-studio-lite) | Lowlight Studio Lite: a free music mixing dashboard |
| [**thock-analytics-lite**](https://github.com/intellaralabs/thock-analytics-lite) | Oak Dial Lite: a free SaaS analytics dashboard |

Need more? [Thock UI Pro](https://thock-ui.vercel.app/pro) adds 46 signature components and blocks, and the
[full templates](https://thock-ui.vercel.app/templates) have 12–13 screens each.
